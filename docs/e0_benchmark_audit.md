### B3. 结论（修正此前假设）

1. **删除不是"按模糊度挑选"，而是按类整体清除**：外部两源中 Bus/Minibus/Truck/van 100% 被删，Car/Taxi/Moto 100% 保留。不存在"困难 Car 保留、困难 Van 删除"的梯度。
2. **batch_12 的 Van（现 merge8 的 Van 类，唯一手工标注 Van 源）一框未删** → "Van 因模糊被删导致 selection bias"的假设**被否**。当前 v10 基准与 E0 不受此影响。
3. 真实存在的偏差是另一种：外部源的全部卡车/巴士内容（4,130 框）变成**负样本（背景）**，同时其 Car/Taxi 成为正样本 → v2/v3 训练配方存在"压制卡车/巴士外形"的系统性负偏置。这解释了 v2/v3 系 run 只有 0.73 而 batch_12 系 0.85。
4. 附带发现：v2 基准的 valid/test GT 同样删除了这些模糊框 → **难正例从评测中消失，v2/v3 系的 val 分数被系统性抬高**。该基准不可作为最终裁判。

## E. Random variance（Task 5/E）

- 真实存在的同配置双跑两组：0339≡0343（0.733/0.733）、0200≡1001（0.956/0.956），**指标逐位一致（5 位小数）**，权重非逐位一致 → 本机同卡训练对指标近似确定，run 间随机方差 ≈ 0。
- 因此历史报告中"0916(0.887) vs 0950(0.854) 的 ±3 分是 seed 方差"的说法**不成立**：0950 的权重是 11 类 v9 模型，该差异是数据/进程错配，不是随机性。
- 真正的 seed 方差目前未测。本阶段遵守"禁止新优化/训练"未重训；建议下一阶段 E0 双 seed 复跑各一次（约 2×4.7h）实测。

## 决策规则判定（按 Task 7 后的规则）

1. **Van 问题主要在 <0.01？** —— 是（34.6%/24.7%），但 0.01–0.05 仍有 7–18% 的本底混淆。→ **优先 imgsz 640→960**，随后 hard-negative；re-weight 降为第二优先。
2. **test 显著低于 val？** —— 否（0.897 vs 0.888）。v10 内部划分健康，暂不需要怀疑数据域问题；但 Van 与 Motorcycle 在 clean 子集/跨 split 的波动提示部署域（1280px + 鱼眼）仍是独立风险项。
3. **ambiguous Van/LGV 删除率远高于 Car？** —— 形式上成立（外部源 Truck/van 100% 删 vs Car 0% 删），但机制是**类级整删**而非模糊度筛选；batch_12 的 Van 未被删。→ 对**当前 v10 路线无影响**；若未来重回 merged 数据路线，必须先修复"删除类同时从 val/test GT 移除"的基准缺陷。
4. 立即行动项（非训练类）：**修复 `main.py` 的 MODEL_PATH → 0916 best.pt**；将 0950 标记为作废。

## 后续建议顺序

1. 修 main.py 指向（0 成本，立即）。
2. E0 双 seed 复跑（实测方差，之后所有实验以 mean±std 报告）。
3. imgsz 960 诊断训练（对照 E0，Van<0.01 桶为重点观察）。
4. 若 960 后中大桶 Van→Car 仍 >10%：hard-negative / re-weight 实验。
